# 🎬 Netflix Content & Trends Dashboard — Power BI

## 📌 Overview
An interactive Power BI dashboard that analyzes the Netflix catalog to uncover insights into movies vs. TV show distribution, top genres, release trends over time, rating classifications, and regional content availability.

## 📸 Dashboard Preview
![Netflix Dashboard](Netflix%20dasboard%20ss.png)

## 🛠️ Tools Used
* **Business Intelligence:** Power BI Desktop
* **Data Modeling:** DAX measures and custom conditional formatting
* **Visuals:** Custom slicers, tree maps, donut charts, and trend lines

## 📊 Key Insights
* **Content Breakdown:** Ratio of Movies to TV Shows across different release years and additions to the platform.
* **Genre & Rating Distribution:** Analysis of popular genres and target audience demographics (TV-MA, PG-13, TV-14, etc.).
* **Geographic Trends:** Identification of top content-producing countries and localized catalog growth.
